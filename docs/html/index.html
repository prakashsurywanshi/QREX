QREX Documentation

QREX — a property management and sales CRM for real-estate agencies, built by Qodeigence Infocircle Private Limited. Three document sets are published here:

  • User Manual — for the people who use QREX day to day (agents, marketing, accounts, admins).
  • How QREX Works — drawings, screen designs and data tables that show how the system fits together.
  • Technical Documentation — architecture, data model, permissions and operations for the people who build and run it.
