# Generated Word documents

Do not edit these files by hand. They are generated from the Markdown sources.

| File | Contents |
| --- | --- |
| `QREX-User-Manual.docx` | The full **User Manual** (docs/user-manual/) as a modern Word document |
| `QREX-User-Manual.doc` | The same, in legacy Word 97 format |
| `QREX-Technical-Documentation.docx` | The full **Technical Documentation** (docs/*.md) as a modern Word document |
| `QREX-Technical-Documentation.doc` | The same, in legacy Word 97 format |

## Regenerating

Requires **LibreOffice** (`soffice`) on the PATH.

```sh
npm run docs:doc
```

See [`../html/README.md`](../html/README.md) for the HTML pages, which are generated in the same run.
